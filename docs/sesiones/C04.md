## 1. Marco y Visión del Producto

A partir de las pruebas de usabilidad realizadas con el dataset real `Notas.xlsx` y las directrices metodológicas del docente, se identificó la necesidad de dar un salto cualitativo hacia una experiencia de usuario **Chat-First** (inspirada en la fluidez de *Julius AI* y *ChatGPT Data Analyst*), eliminando la fricción cognitiva y erradicando los defectos visuales que entorpecían la interacción del tesista.

El tesista de posgrado o pregrado que ingresa a TesisStat AI no busca enfrentarse a paneles de configuración laberínticos ni a terminología de depuración interna. Su objetivo es dialogar con un asistente que comprenda sus datos desde el primer segundo, diagnostique sus variables y lo conduzca de la mano a través de análisis deterministas rigurosos.

## 3. Fase C04-B: Corrección Integral y Simplificación Radical

Tras la primera entrega, se resolvieron de raíz tres requisitos arquitectónicos y de flujo fundamentales:

### Problema 1: Aterrizaje Directo en el Asistente IA (Chat-First Real)
- **Diagnóstico:** Al crear o abrir una investigación, el sistema redirigía a `#project=<id>&section=home`, mostrando una pantalla obsoleta de bienvenida ("Inicio. Tu proyecto, paso a paso").
- **Implementación:**
  - `ResearchProjects.tsx`: Redirección inmediata a `navigateProject(saved.id, 'assistant', null, true)` al crear un proyecto, y a `navigateProject(id, 'assistant')` al abrir un proyecto existente.
  - `navigation.ts`: La sección predeterminada es ahora `'assistant'`.
  - Pestañas superiores simplificadas y limpias: **`[Asistente IA]`**, **`[Datos]`**, **`[Contexto]`**, **`[Resultados]`**. Se eliminó la pestaña obsoleta `[Inicio]`.
  - Barra lateral de navegación: Las herramientas secundarias (`Documentos`, `Metodología`, `Instrumento`, `Informes`) se agrupan en una sección colapsable `<details className="rp-secondary-collapse">` (cerrada por defecto), eliminando el ruido cognitivo.

### Problema 2: Creación de Proyecto Asistida con Prompt Maestro
- **Diagnóstico:** El formulario de creación no permitía aprovechar tesis preexistentes analizadas con ChatGPT, Claude o Gemini.
- **Implementación:**
  - `masterPrompt.ts`: Exportación del prompt estructurado oficial de extracción metodológica (Título, Pregunta, Objetivo General, Específicos, Hipótesis, Variables, Población en JSON).
  - `ProjectForm.tsx`:
    - Botón **«📋 Copiar prompt de tesis para otro chat»** con feedback visual (*«✓ Prompt copiado al portapapeles»*).
    - Área de texto **«Respuesta del otro chat (JSON o texto)»** para pegar la salida de ChatGPT/Claude/Gemini.
    - Explicación clara y no bloqueante para el alumno.
  - Al guardar: Si el usuario incluyó una respuesta asistida, `ResearchProjects.tsx` invoca automáticamente `contextApi.suggest` y `contextApi.apply` para pre-poblar los objetivos e hipótesis en el nuevo proyecto antes de abrir el Asistente IA.

### Problema 3: Visor de Datos Limpio (Simplificación Radical de "Datos")
- **Diagnóstico:** La sección de Datos mantenía pestañas de ingeniería complejas (`[Archivos y tablas]`, `[Revisar datos y variables]`, `Herramientas avanzadas ▼`, `[Instrumento y puntuaciones]`).
- **Implementación:**
  - `ProjectDataWorkspace.tsx`: Transformado en un **Visor Limpio de Datos**:
    - **Selector de tabla:** Dropdown elegante para alternar entre hojas o tablas cargadas.
    - **Data Grid limpio:** Previsualización tabular de las filas y columnas reales con scroll suave y encabezados claros.
    - **Variables detectadas:** Resumen con micro-insignias semánticas (`numérico`, `texto`, `fecha`) basadas en análisis directo de tipos.
    - **Botón secundario discreto:** `«+ Subir otro archivo»` para cargar datasets adicionales sin saturar la pantalla.
    - Compatibilidad hacia atrás: Rutas con `view=legacy`, `view=quality` o `view=preparation` continúan delegando a `ProjectDatasets` para flujos avanzados o pruebas heredadas.

## 6. Protocolo de Validación en Navegador

1. **Creación de Proyecto con Prompt Maestro:**
   - Crear una investigación. Abrir el acordeón *«Contexto metodológico de tesis (opcional)»*.
   - Pulsar `[📋 Copiar prompt de tesis para otro chat]`: Confirmar feedback *«✓ Prompt copiado al portapapeles»*.
   - (Opcional) Pegar una respuesta JSON o texto en el campo correspondiente.
   - Pulsar `Crear investigación`.
2. **Aterrizaje Directo en el Asistente IA:**
   - La aplicación navega de inmediato a `section=assistant`, mostrando el chat amplio y despejado en el área principal.
   - Observar el saludo cálido y la pregunta orientadora inicial.
3. **Visor Limpio de Datos:**
   - Cargar `Notas.xlsx` desde el chat o acceder a la pestaña superior `[Datos]`.
   - Verificar la visualización tabular limpia, el selector de tabla y los chips de tipo de variable (`numérico`, `texto`, `fecha`).
4. **Pestañas Superiores Claras:**
   - Solo 4 pestañas visibles: `[Asistente IA]`, `[Datos]`, `[Contexto]`, `[Resultados]`.
   - Las herramientas secundarias (`Documentos`, `Metodología`, etc.) se encuentran discretamente en la barra lateral bajo `Herramientas secundarias`.
